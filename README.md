# CrossApp

Наскрізний проєкт з крос-платформного програмування.
Предметна область: Замовлення. 
Сутності: Customer, Product, Order, OrderLine.
Призначення: оформлення замовлень покупцями, облік товарних позицій та розрахунок підсумкової вартості замовлення.

## Структура Solution
- `src/Core/` — бібліотека класів (Class Library). Містить базову логіку, збір системної інформації та майбутню доменну модель.
- `src/Cli/` — консольний застосунок. Відповідає суто за відображення та форматування виводу.
