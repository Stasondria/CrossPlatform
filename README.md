# CrossApp

Наскрізний проєкт з крос-платформного програмування.

## Предметна область
**Замовлення**
- **Сутності**: `Customer` (клієнт), `Product` (товар), `Order` (замовлення), `OrderLine` (рядок замовлення).
- **Призначення**: Оформлення замовлень покупцями, облік товарних позицій та розрахунок підсумкової вартості замовлення.
